# Changelog

## Phase 1

- Added the Flask application factory, configuration, SQLAlchemy models,
  migrations, response envelope, error handling, health endpoint, and ERD.

## Phase 2

- Added JWT authentication, token revocation, password workflows, lockout,
  rate limits, and reusable RBAC guards.

## Phase 3

- Added users, staff, courses, batches, and students resource APIs with
  pagination, validation, and object-level student isolation.

## Phase 4

- Added leads, follow-ups, counselor scoping, and transactional conversion.

## Phase 5

- Added attendance, assessments, marks, trainer ownership, and percentages.

## Phase 6

- Added fee plans, installments, payments, receipts, voids, dues, and student
  fee summaries.

## Phase 7

- Added placement companies, drives, eligibility checks, applications, offer
  details, certificate eligibility, issuance, and downloads.

## Phase 8

- Added secure materials, notifications, dashboards, reports, settings, and
  public settings APIs.
- Added the shared frontend API client, login/password-reset integration,
  protected-page token wiring, role-aware shell identity, and sign-out.

## Phase 9

- Added idempotent demo seed data, production seed protection, security
  headers, OpenAPI overview, and delivery documentation.
